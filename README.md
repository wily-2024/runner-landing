# Runner Automatizaciones — Landing Page

Landing page para servicios digitales enfocados en negocios de belleza
(peluquería, estilismo, maquillaje y spa/masajes).

## Contenido de esta carpeta
- `index.html` — la página completa (HTML + CSS + JS en un solo archivo)
- `runner-hero-qrmaps.jpg` — la foto animada del hero (escaneo de QR + presencia en Google)
- `runner-qr.png` — el código QR flotante que aparece en la esquina inferior izquierda

Las fotos de los 3 servicios (peluquería, maquillaje, spa) siguen alojadas
externamente (Unsplash) — solo estos tres archivos deben ir juntos en la
misma carpeta para que la página funcione al 100%.

## Cómo publicarla en GitHub Pages

1. Entra a github.com y crea un repositorio nuevo — por ejemplo `runner-landing`
   (público, sin README ni .gitignore, para no chocar con estos archivos).
2. Sube estos tres archivos directo a la raíz del repositorio — puedes
   arrastrarlos en "Add file → Upload files" desde el navegador, sin
   necesidad de usar la terminal.
3. Ve a Settings → Pages.
4. En "Branch", elige `main` y la carpeta `/ (root)` → Save.
5. Espera 1–2 minutos. Tu página quedará publicada en:
   `https://<tu-usuario>.github.io/runner-landing/`

## Importante sobre el QR
El código QR que ya está insertado en la página (y en la tarjeta imprimible
que te compartí antes) apunta a:
`https://wily-2024.github.io/runner-landing/`

Si publicas el repositorio con otro nombre de usuario o de repositorio,
la URL final va a ser distinta a esa — avísame la URL real una vez publicada
y te regenero el QR para que apunte al lugar correcto.
